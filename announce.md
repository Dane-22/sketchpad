# 🚀 Project Updates & Release Notes

We're excited to announce a massive set of new features and improvements to the engineering planner platform! Here is everything included in this latest update:

## 👥 Real-Time Collaboration Upgrades
* **Named Cursors:** Anonymous cursors are a thing of the past! User cursors now proudly display real names.
* **Online Users Widget:** Added a new floating widget to instantly see who is currently active and online on the canvas.
* **Unique User Ink:** Each collaborator is now automatically assigned a distinct ink color, making it easy to see who drew what.

## 🎨 New & Improved Drawing Tools
* **Freehand Tool Fixed:** The freehand drawing tool has been completely overhauled for smoother, continuous strokes.
* **Custom Line Colors:** You now have full control over the color options for your lines and drawings.
* **Arrow Tool:** Added a dedicated Arrow Tool to make pointing out details and annotating plans faster than ever.
* **Continuous Eraser:** Introduced a robust eraser tool with continuous hover-to-erase functionality.
* **Ortho Mode Fixed:** The Ortho functionality for drawing perfectly straight vertical and horizontal lines has been fixed and optimized.
* **HD Canvas:** High definition rendering is now active for crisp, crystal-clear blueprints.

## 💬 Team Messenger Enhancements
* **Resizable Chat:** The Team Messenger widget can now be resized to fit your workspace perfectly.
* **File Sharing & Import:** You can now send files directly within the team messenger! Plus, you can instantly import shared CAD, PDF, and Image files right onto the canvas.

## 🖼️ Media & UI Improvements
* **Image Cropping:** Added brand new crop functionality allowing you to easily crop imported images and blueprints directly on the canvas.
* **Cleanup:** Removed outdated and unused features to keep the interface clean and fast.

---
*Run `git pull origin main` and `docker compose up -d --build` on your production server to deploy these updates!*
